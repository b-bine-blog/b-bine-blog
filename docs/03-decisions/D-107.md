# D-107 서비스 이름은 "블바인 블로그"

- 날짜: 2026-10-12
- 관련 항목: USR, BLG(화면 전체), D-66
- 상태: 확정

## 결정
서비스 이름을 "블바인 블로그"로 정한다. "블로그"의 "블"과 combine(컴바인, 합치다)의 "바인"을 합친 말로, 여러 사람이 함께 블로그를 운영한다는 뜻이다.
- 화면 제목(`<title>`), 상단 로고 글자, 글 상세 og 태그의 사이트 이름, 인증 메일 제목·본문에 이 이름을 쓴다.
- 코드 패키지(`com.mainblog`), 저장소 이름, 문서 안의 "메인블로그"(가입·로그인을 하는 중심 사이트라는 뜻)는 그대로 둔다.
- 화면의 나뭇잎 장식 그림은 모두 뺀다. 좋아요·뒤로 가기 같은 기능 아이콘(img/icon)은 남긴다.

## 이유
사용자가 2026-10-12에 이름을 "블바인 블로그"로 정하고 그림을 빼기로 함.
