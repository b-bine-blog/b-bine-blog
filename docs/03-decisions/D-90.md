# D-90 메인 관리자는 블로그 활동을 하지 않음

- 날짜: 2026-10-07
- 관련 항목: SEC-09, 2장 권한 표
- 상태: 확정

## 결정
메인 관리자 계정은 일반 회원과 분리하고, 블로그 생성·참여 신청·글쓰기·댓글·좋아요·팔로우를 하지 않는다. 2장 권한 표의 메인 관리자 열을 X로 고침 (SEC-09, 2장)

## 이유
관리자가 블로그 활동을 하면 관리 대상과 이해관계가 생기고, 관리자 계정과 회원 계정이 섞임

## 이전 내용 → 바꾼 이유
2장 권한 표에서 메인 관리자가 블로그 생성·참여·글쓰기·팔로우·댓글·좋아요를 할 수 있다고 되어 있었음 → 팀 결정에 맞춰 X로 바꿈. 같은 표의 "참여 승인·멤버 강퇴"도 ADM-01·D-44에 맞춰 X로 고침
