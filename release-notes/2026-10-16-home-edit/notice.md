# v1.22 메인 화면을 내 마음대로

## 편집 모드가 생겼어요
닉네임 메뉴의 "내 정보" 아래 "편집"을 누르면 편집 모드가 돼요.
로고 옆에 "기본으로"와 "완료" 버튼이 생겨요.
"완료"를 누르거나 Esc를 누르면 편집이 끝나요.
"기본으로"를 누르면 모든 자리와 크기가 처음대로 돌아가요.
바꾼 자리와 크기는 계정마다 기억해요.

왜 바꿨나요: 자주 쓰는 버튼과 칸을 원하는 곳에 두고 쓸 수 있게 하고 싶었어요.

## 머리 메뉴 버튼을 옮길 수 있어요
편집 중에는 밝기·알림·닉네임 버튼을 끌어 화면 어디에나 둘 수 있어요.
옮긴 버튼의 제자리에는 반투명 빈 칸이 남아요.
버튼을 그 빈 칸에 다시 놓으면 제자리로 돌아가요.

## 메인 화면 칸을 고칠 수 있어요
편집 중에는 메인 화면의 "블로그 둘러보기"와 "글" 칸을 바꿀 수 있어요.

| 하는 일 | 방법 |
|---|---|
| 칸 지우기 | 칸 오른쪽 위 "삭제" 버튼 |
| 칸 다시 넣기 | 맨 아래 "+ 추가"에서 지운 칸 고르기 |
| 자리 바꾸기 | 칸 제목줄을 잡고 끌기 |
| 크기 바꾸기 | 칸 오른쪽 아래 손잡이를 끌기 |

너비를 줄이면 칸끼리 옆으로 나란히 놓여요.
높이를 줄인 칸은 안에서 내려 볼 수 있고, 제목줄은 맨 위에 남아요.

## 유튜브 영상을 칸으로 띄울 수 있어요
"+ 추가"에 유튜브 주소를 넣으면 메인 화면에 영상 칸이 생겨요.
영상, 재생목록, 채널 라이브 주소를 넣을 수 있어요.
칸은 5개까지 넣을 수 있어요.
넣은 순서대로 위에서부터 놓여요.

왜 유튜브만인가요: 아무 사이트나 띄우면 가짜 로그인 화면 같은 위험이 있어서 유튜브만 받아요.

주의: 휴대폰처럼 좁은 화면에서는 칸이 한 줄을 다 써요. 영상 주인이 퍼가기를 막아 둔 영상은 재생되지 않아요.
