# v1.24 글 목록이 빨라졌어요

## 메인 글 목록을 더 빨리 보여 줘요
메인 화면의 최신 글·인기 글 목록을 불러오는 방식을 바꿨어요.
글이 아주 많아져도 목록이 늦게 뜨지 않아요.

| 화면 | 전 | 후 |
|---|---|---|
| 메인 최신 글 | 17.8초 | 1.0초 |
| 메인 인기 글 | 13.9초 | 1.0초 |
| 최신 글 1000쪽 | 26.8초 | 1.0초 |
| 제목 검색 | 3.1초 | 1.9초 |

왜 바꿨나요: 글이 30만 개로 늘어난 상황을 미리 시험해 보니 목록이 10초 넘게 걸렸어요. 사이트가 커져도 느려지지 않게 미리 고쳤어요.

주의: 위 숫자는 글 30만 개를 넣은 시험 환경에서 잰 값이에요. 지금 사이트는 글이 적어서 차이가 크게 느껴지지 않을 수 있어요.
