# v1.13 서버를 도커로 옮겼어요

## 사이트가 도커 컨테이너에서 돌아가요
사이트를 실행하는 방식을 바꿨어요. 이제 Java 실행 환경까지 함께 담은 도커 컨테이너로 돌아가서, 서버에 깔린 Java 버전과 상관없이 같은 모습으로 떠요. 쓰시는 화면과 기능은 그대로예요.

왜 바꿨나요: jar로 실행하면 서버의 Java 버전이 맞아야 사이트가 뜨기 때문이에요.

## 업데이트 중에도 끊기지 않게 준비했어요
새 버전을 옆 자리에 먼저 띄우고, 제대로 뜬 것을 확인한 뒤에 옛 버전을 내리는 방식(무중단 배포)을 넣었어요. 서버 설정을 마치면 업데이트할 때 "잠시 점검 중" 화면 없이 바로 새 버전으로 넘어가요.

## 소셜 가입 화면에 안내 문구를 더했어요
소셜 로그인으로 처음 가입할 때 이메일 인증 단계에 "첫 가입 시 (서비스) 이메일 인증 필요" 안내가 보여요.
