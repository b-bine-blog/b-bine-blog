# v1.23 글을 원하는 곳으로 공유해요

## 공유 버튼이 메뉴로 바뀌었어요
글 상세의 "링크 복사" 버튼이 "공유" 버튼으로 바뀌었어요.
누르면 공유할 곳을 고르는 메뉴가 열려요.

| 항목 | 하는 일 |
|---|---|
| 링크 복사 | 글 주소를 복사해요 |
| 카카오톡 | 카카오톡 친구나 채팅방에 미리보기 카드로 보내요 |
| X(트위터) | X에 올리는 창을 열어요 |
| 페이스북 | 페이스북에 올리는 창을 열어요 |
| 텔레그램 | 텔레그램으로 보내는 창을 열어요 |
| 다른 앱 | 휴대폰의 공유 창을 열어요(인스타그램 등) |

메뉴 밖을 누르거나 Esc를 누르면 닫혀요.
일부 공개 블로그의 글은 지금처럼 볼 수 있는 공유 주소로 보내져요.

왜 바꿨나요: 링크를 복사해서 붙여 넣지 않고 원하는 곳으로 바로 보낼 수 있게 하고 싶었어요.

## 요청 횟수 제한을 더 정확하게 세요
로그인 시도나 좋아요처럼 너무 자주 누르면 잠시 막는 기능이 있어요.
지금까지는 서버 두 대가 따로 세어서 실제로는 정해진 횟수보다 더 많이 받을 수 있었어요.
이제 두 서버가 같은 기록을 함께 보고 세요.

주의: "다른 앱"은 공유 창을 지원하는 브라우저(주로 휴대폰)에서만 보여요. 비공개 블로그 글과 공지에는 공유 버튼이 없어요.
