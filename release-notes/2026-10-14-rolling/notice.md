# v1.15 배포 중에도 사이트가 끊기지 않아요

## 업데이트할 때도 사이트가 계속 열려요
이제 사이트를 돌리는 앱이 늘 두 개 떠 있어요. 새 버전을 올릴 때는 하나씩 차례로 바꾸고, 그동안 다른 하나가 접속을 받아요. 평소에 하나가 멈춰도 다른 하나가 받아서 "점검 중" 화면 없이 계속 쓸 수 있어요.

왜 바꿨나요: 배포할 때만 안 끊기는 방식보다, 평소에 문제가 생겨도 안 끊길 가능성이 높은 방식이 좋다고 봤어요.

## 문서를 별도 저장소로 나눴어요
요구사항·결정 기록·기능 명세 같은 문서를 소스 코드와 다른 GitHub 저장소(b-bine-blog-docs)로 옮겼어요. 사이트 화면은 그대로예요.

왜 바꿨나요: GitHub에서 문서와 소스 코드를 나눠 달라는 요청을 받았어요.

## GitHub 설명(README)을 읽기 쉽게 정리했어요
긴 문단을 소제목, 표, 명령어 칸으로 나눠 처음 보는 사람도 따라 하기 쉽게 고쳤어요.

왜 바꿨나요: 설명 부분이 길게 이어져 가독성이 떨어졌어요.
